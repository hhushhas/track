## Push transport decision
Audited the notification client, Convex delivery path, schema, tests, and docs
read-only. Confirmed `expo-notifications` can return native APNs/FCM tokens via
`getDevicePushTokenAsync()`, so direct provider delivery does **not** require
replacing the client library. **Recommendation adopted:** replace Expo Push
Service transport with direct APNs and FCM delivery, keeping
`expo-notifications` for permissions, channels, foreground handling, response
listeners, and native token acquisition.

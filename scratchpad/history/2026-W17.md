# 2026-W17 (Apr 20–26) — digest

Source: 1 session log (`ui-ux-session-log-2026-04-25.md`), condensed 2026-08-23.

## Product model locked
Shifted from product grilling into UI/UX. Established the ubiquitous language:
Record is the main object, chat creates evidence, AI produces Draft Records,
Owner/Admin and assigned Staff review and classify. Client sees official/billable
records; formal acknowledge/dispute stayed out of the model. Internal-side term
renamed to **Staff**. Track supports multiple Projects with no
organization/workspace layer — the Project switcher is the navigation surface.

**Groups** became first-class inside Projects: every message belongs to exactly
one Group; defaults are `general`, `internal`, `commercials`; each has an explicit
member list seeded by role defaults. Group membership is the access boundary for
messages, Draft Records, and Records.

**`@track`** added as an in-conversation assistant mention — distinct from AI
Review. AI Review proposes Draft Records; `@track` answers questions inline with
evidence citations, natural yes/no/partly/not-enough-evidence semantics, no intent
judgment, current Group by default.

## Scope locked into Track
Attachments, push notifications, immutable audit history, Project Record export,
observability, avatar uploads (Convex File Storage), global + per-Group
notification settings (Group wins), invite flows, full web/mobile parity, and both
app-store submissions. MVP/POC framing dropped — Track is the product scope.

## Technical decisions
Convex, TanStack Start, Expo, AI SDK/OpenRouter, shadcn/Tailwind, Cloudflare
Workers, pnpm/turbo monorepo. Better Auth for auth; TypeScript 6; TOTP + recovery
codes for 2FA (no SMS/email OTP). Project/Group creation and membership changes
restricted to Owner/Admin; Staff and Client participate via chat, not structure.
Incremental AI Review defined as per-Group cursor-based review with manual deep
re-scan. Attachment extraction: text and embedded-text PDFs/docs first, OCR and
transcription later. Mobile UI: NativeWind + selective React Native Reusables on
Track's own design system. Web Push via direct VAPID.

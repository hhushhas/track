## Implementation and ship (06-05)
Branch `context-import-box-memory`. Added `@upstash/box@0.4.4` and `zod@4.3.6`;
Convex tables `projectMemoryBoxes`, `memoryImports`, `memoryPathLocks`. Memory
policy helpers with tests for path safety, group-scoped access, context edit
limits, prompt-injection promotion rejection, and bash command policy. Live/fake
Box adapter boundary — default tests use the fake and need no Upstash creds.
Box-backed actions split into `convex/memoryActions.ts` with `"use node"`.

Link imports fetch public pages into normalized scratch; file imports reuse
attachment text extraction; pasted imports write `paste.md` with the same
metadata header. Bash execution prepares a scoped run view (`context.md` plus
only allowed group scratch), wraps with a configured timeout, and schedules
cleanup of old run views. Web import dialog added to the group chat composer.

**Live verification** passed end to end on dev and then production
(`fleet-manatee-941` + Cloudflare Worker): Box create/read/write, `context.md`
edit, scoped bash, client denied Internal scratch read (`group_scope_denied`),
blocked `ssh` (`remote_shell_or_transfer_command`), and `memory_box.deleted`
audit on project deletion. Two bugs found and fixed by live smoke: Convex
extra-field validator failures, and a concurrent first-use Box creation race
(`ensureProjectBox` now retries the pointer lookup after name collisions).
